# 開發紀錄

## 2026-11-18 Windows v1.0.0

- 需求：小柯機器人建築平面圖轉 3D 工具；Windows 先做，之後 Mac、線上版、iPhone／iPad（線上安裝）、Android；要有更新、小柯＋主題圖示與捷徑、語音動態教學。開發中使用者追加：要能用在 VR 與 VR 眼鏡（→ WebXR 模式＋GLB／USDZ 匯出）。
- 參考專案 akaiHuang/ai-floorplan-to-3d：Express 後端把圖丟給 GPT-4o 回 JSON、Three.js 方塊牆。它必須有 OpenAI 金鑰才能用，所以本專案改成：
  1. 自寫本機辨識演算法（不需金鑰、離線、零點幾秒），AI 變成選配；
  2. 牆用中心線段＋門窗自動挖洞（參考專案的門窗只是貼在牆上的方塊）；
  3. 不需要伺服器，整個在瀏覽器／Electron 畫面裡跑，方便之後做線上版與手機版。
- 範例平面圖由 `scripts/make_samples.py` 畫（實心牆兩房一廳、空心雙線牆三房兩廳＋獨立柱），同時輸出答案給測試比對。
- 辨識調整過程：
  - 柱子（塗黑方塊）讓牆厚估錯 → 只統計「細長」筆畫。
  - 空心牆：白間距直方圖估閉合半徑；閉合後窗的三條線也被填滿 → 空心牆內橫切有 ≥3 條線的段落切成窗。
  - 閉合把文字也變粗 → 牆段依相接關係分群，總長不到最大群 20% 的丟掉。
  - 預設依牆厚換算比例誤差 25%（外牆 20 cm、內牆 12 cm）→ 改用門寬中位數 0.9 m，誤差 4%。
  - 模糊雜訊掃描（自製測試圖）：內牆漏抓 → 門檻 0.6T 降到 0.45T；文字被當成柱 → 柱要方或圓、實心、四周空。
- 測試：vitest 23 項；桌面 e2e 29 項（範例辨識、指令、復原、夜晚、漫遊、六種匯出與檔頭檢查、重新開啟專案、歷史、語音教學全程），開發版與已安裝版都通過。
- 已 /S 安裝到 %LOCALAPPDATA%\Programs\XiaokeFloorplan（桌面＋開始選單捷徑）。
- 使用者同意後建公開 repo achir1015/xiaoke-floorplan，發佈 v1.0.0（安裝版＋免安裝版）；已安裝版的「檢查更新」實測讀得到 v1.0.0。

## 2026-11-18 v1.2.1 辨識改進（使用者回報只辨識約 60%）

- 使用者的平面圖（黑色實心牆、門開在牆角、窗一路畫到轉角）只抓到下半部。原因：
  1. 「不跟主建築相連的牆群當雜訊刪掉」的規則：上半部和下半部之間只靠窗、門相連，整片被刪。→ 同一直線隔著缺口（10 倍牆厚內）算相連；夠長（≥25 倍牆厚）的牆群隔著轉角門窗跟主建築相鄰也留下，文字太短不會被連進來。
  2. 只找「同一直線上兩段牆中間」的門窗，門開在牆尾、緊貼另一道牆的找不到 → 從牆尾沿牆方向往外找，碰到別的牆就是候選開口。
- 門窗判斷改用證據：有開門弧線（以缺口內任一點為軸心、半徑試缺口寬的 55%～100%，用較寬鬆的淡線門檻）＝門；兩條以上平行線＝窗；都沒有＝走道開口，不放門。也拿掉「>1.6 m 當落地窗」。
- 使用者的圖放在 tests/local/（不進 git），tests/local.test.ts 有檔案才測。
